# PRS.AssetVerify v6

Multi-company physical-verification PWA for iOS and desktop.

Main changes in v6:
- New target URL: https://prsav.github.io/PRS/
- Fresh v6 database tables; v5 records are not shown in v6.
- Company-level username/password instead of member-level credentials.
- Team members require only name + Admin/Verifier role.
- Clear Forgot Company Password option on login.
- Team-member selector after company login.
- Admin-only delete/company/member management; Verifier cannot delete photos.
- Shared D1/R2 data, location/status/condition filters, AI multi-asset detection, 1 MB photo compression, gallery upload, remarks, usage and Excel export retained.
